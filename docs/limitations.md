# Limitaciones

- El inventario no tiene fecha ni historial de movimientos.
- No existen datos de reposición, lead time, pedidos rechazados o nivel de servicio.
- Costo y precio se tratan como constantes durante todo el período.
- La ganancia calculada es bruta, no neta.
- La cobertura usa los 90 días calendario terminados el 30/09/2023 como aproximación de demanda futura y supone que la fotografía de inventario es comparable con esa fecha.
- Hay 157 combinaciones tienda-producto sin registro de inventario; esto puede reflejar surtido, no necesariamente un error. Veintitrés tuvieron demanda reciente y merecen validación.
- El período contiene solo un año completo, insuficiente para confirmar estacionalidad anual estable.
- Los umbrales de cobertura son reglas de priorización, no políticas oficiales de la empresa.
- El movimiento opuesto de Magic Sand y Colorbuds muestra un cambio de mix, no una relación causal demostrada.
- El menor crecimiento interanual de septiembre es una observación puntual, no evidencia suficiente de desaceleración.
